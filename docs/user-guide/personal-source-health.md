# 个人来源流健康状态与异常原因

`/sources` 同时显示“用户是否启用”和“是否实际运行”。前者是 Owner 意图；后者表示该流当前满足服务端调度权威，可以被调度，并不表示此刻一定有 HTTP 请求正在进行。

## 健康状态

- `UNKNOWN`：尚无运行观察。
- `HEALTHY`：最近运行成功且没有达到异常阈值。
- `DEGRADED`：仍可调度，但连续零发现、结构变化或字段质量需要关注。
- `UNHEALTHY`：最近运行失败、预算/访问不可用或处于熔断。

## 中文异常原因

页面把稳定原因码翻译为中文，包括 DNS、TLS、超时、HTTP 401/403/404/429/5xx、robots 禁止、需要登录、验证码、付费墙、MIME 不符、解析失败、连续零发现、DOM/结构变化、必要字段缺失、内容过期、预算耗尽和熔断。

系统不会尝试绕过登录、验证码、付费墙、robots、IP 或其他访问控制。连续零发现触发的重新探测只作用于当前流；同一来源的其他健康流继续独立调度。

“下次自愈时间”通常是熔断半开探测时间；“最近成功抓取时间”表示最近一次成功响应；“最近发现内容时间”仅在发现新内容时更新。所有时间在数据库中保存为 UTC，页面按 `Asia/Shanghai` 展示。
