# 自动关系和个人纠错说明

## 自动关系是什么

平台在当前文档版本完成证据处理后，使用确定性身份键、事件归属、报告阶段、型号键、主题归属和服务端置信阈值计算关系。每次决定都会保存算法版本、可选模型版本、0–10000 基点分数、理由代码、输入成员、文档版本和内容 SHA-256。

支持的关系包括：高置信重复、同一事件、后续报告、最终调查、型号别名、版本继承、共同主题和相关内容。模型分数只能作为输入；地区、项目等硬冲突会阻止自动关系。

## 不会被自动合并的内容

- 初报、续报和最终调查报告只建立 `FOLLOW_UP_OF` 或 `INVESTIGATES`，不会作为重复项覆盖。
- 厂商声明、媒体报道和独立验证保留不同 `source_role`，只建立相关内容关系。
- 自动化不删除 Item、Document、DocumentVersion、Claim 或 Evidence，关系失效也只追加状态和失效链。

## 在 Event 详情纠正

在“自动关系与个人纠错”区域可以：

1. 撤销单条自动关系；
2. 将事件成员分配到至少两个子事件；
3. 选择两个或更多成员并标记“保持独立”；
4. 将两个产品成员修正为型号别名或版本继承。

每次操作都需要填写原因，并使用幂等命令 ID 提交。成功后页面重新加载关系；Feed、搜索、日报和缓存失效 generation 在同一数据库事务推进。

## 优先级和重新计算

Owner 撤销会绑定关系种类、成员集合和输入指纹。相同原文版本再次处理时不会重建；当任一成员的当前 DocumentVersion 或内容 SHA-256 发生实质变化时，可以产生一个引用旧决定的新版本。Owner 型号纠正保存为满分的 `owner-correction-v1` 决定，自动任务不能覆盖它。

旧审核工作台仍可读取历史重复、事件、主题和型号候选，但不能新增或提交这些候选。旧表和旧 API 未删除。
