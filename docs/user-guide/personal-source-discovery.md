# 自动发现主题和额度使用说明

## 工作方式

个人研究平台默认每 6 小时运行一次自动发现。系统先读取已经保存的 RSS/Atom、Sitemap 和公开页面证据，再提取跨机构 HTTPS 外链；外链扩展深度固定为 1，自动发现的新来源不会继续产生第二层外链。

百度全网搜索是独立的可选补充。只有 `SRBG_BAIDU_SEARCH_ENABLED=true` 且配置非空 API Key 时才会在免费阶段之后运行。关闭百度、缺少 Key 或月度预算耗尽都不会阻止免费发现，也不会阻止应用启动。页面只显示“关闭、缺少 Key、可用、预算耗尽”，不会返回或展示 Key。

## 编辑研究主题

Owner 在 `/sources` 的“自动发现”区域可以编辑每个固定主题的：

- 关键词：至少保留一个，用于查询与样本相关性评分；
- 排除词：任一排除词命中时，该样本不计为相关；
- 重点地区：用于查询扩展、标签和同分排序，不是硬过滤；
- 启用状态。

主题的代码、名称和数量固定，不能新增、删除或重命名。预置主题为公路、桥梁、隧道、铁路/轨道、数字化、AI/物联网/低空设备，以及安全法规/标准/事故/处罚/整改。

## 每日额度

“今日”按 `Asia/Shanghai` 自然日计算：

- 最多探测 100 个此前未知的机构来源；重复发现和已有充分证据的重评分不重复计费；
- 最多自动启用 20 个来源；合格但超额的来源按总分降序、首次发现时间、UUID 稳定顺延。

总分由主题相关性 35、连接器稳定性 25、样本解析完整度 20、画像证据与置信度 10、内容有效性与时效 10 组成。权威等级和独立性只用于标签、排序和归因，不参与分数或启用门槛。

## 自动启用与手工停用

总分达到 70 只是必要条件。公网与 SSRF、robots、无登录/验证码/付费墙、条款和版权硬门禁、连接器可执行、至少一个真实样本成功解析、证据版本仍然有效也必须同时通过。

Owner 手工停用会写入 sticky 状态。后续重复发现、自动画像和重新评分都不能重新启用该来源；只有 Owner 的显式操作可以改变个人意图。自动评分与启用不会创建、接受或发布 Claim。
