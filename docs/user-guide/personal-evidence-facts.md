# 证据事实与 AI 判断

## 证据事实

`EVIDENCE_FACT` 是能够由当前原文证据直接证明的字段。系统会检查 Evidence ID、所属文档版本、摘录定位、数字/金额/日期一致性、企业声明归因、官方法律/责任/因果原文、证据生命周期、冲突和提示注入。通过后仍显示“机器整理/未人工复核”，便于 Owner 回到原文复查。

文档换版、撤回、替代或证据失效会使旧事实立即退出当前投影，并排队重新处理。历史记录保留用于审计。

## AI 判断

`AI_JUDGMENT` 是模型候选，不是已验证事实。即使模型置信度很高，只要未满足证据门禁，就只能在 Event 详情的独立“AI 判断（未验证）”区域预览。它不会进入资讯卡摘要、搜索、日报、推荐、通知或未验证时间线。

## 模型不可用

DeepSeek 不可用、余额不足或预算关闭时，题录和原文链接继续可用。本地规则仅提取标题、发布者、文号/型号、明确日期、整数数量和带币种金额，并要求原文定位；系统不会生成替代摘要或补全证据中没有的信息。
