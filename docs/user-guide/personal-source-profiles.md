# 个人来源画像与置信度

来源画像用于减少日常手工分类，不是来源启用、发布批准或人工审核。页面中的“自动结果”来自版本化本地规则和可选的 DeepSeek 语义候选；权威与独立性由服务端规则最终计算并标记 `AUTO_INFERRED`。

## 字段

- 工程行业、内容域：可多选，使用平台受控枚举。
- 语言：BCP 47 标签；国家使用 ISO 两字母代码，地区使用受控区域代码。
- 来源声明角色：描述来源对自身内容的角色声明，不等同于事实真实性。
- 权威等级与独立性等级：两个独立维度，不合并为“可信度”。
- RSS、Sitemap、API、PDF 等技术事实来自实际响应和流配置，只读且不可个人覆盖。

## 置信度

每个语义字段单独显示 0—100 的推断置信度：`0` 表示证据不足，`50` 表示只有经校验的模型候选，`70` 表示一个确定性线索或模型与本地线索互证，`85` 表示两个独立本地证据，`95` 表示协议、注册域或明确机器事实。总体置信度取所有语义字段的最小值，不用平均数掩盖薄弱字段。

`COMPLETE` 要求模型候选通过本地 Schema/证据校验且所有字段均有依据；其他情况为 `PARTIAL`。预算关闭、模型余额不足、模型不可用或提示注入不会阻断采集。

## 个人覆盖

在 `/sources` 选择“查看画像”即可编辑语义字段。覆盖值与自动值分别保存，后续自动重跑不会覆盖个人选择；清空单项可恢复该字段跟随自动结果，“一键撤销覆盖”恢复全部字段。个人覆盖不伪造自动置信度，也不改变来源运行、发布或安全状态。
