# 个人用户：添加公开 URL

1. 本机执行 `make dev`，浏览器打开 <http://127.0.0.1:3000/sources>。
2. 在“添加 URL”中粘贴公开的 `https://` 地址，点击“保存并探测”。来源主页、栏目列表、RSS/Atom、Sitemap、JSON API 和直接 PDF 均可直接粘贴。
3. 页面会显示“探测中”，完成后列出每个采集入口的类型和状态。失败时会保留来源及原因，可点击“重新探测”。

系统不会要求填写 CSS 选择器、JSON Pointer、连接器或试运行表单，也不会尝试绕过登录、验证码、付费墙或 robots。`已就绪` 只表示入口已安全识别；PERS-02 不会启动长期采集。
