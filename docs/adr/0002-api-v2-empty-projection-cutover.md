# API v2 与空投影代际切换

状态：Accepted。土木工程情报读取、搜索、热点、Event 阅读、媒体和 Owner 复核采用 `/api/v2`，并原子切换到空的 v2 投影；被替代的 v1 读取端点立即撤除。此决定以短期空 Feed 换取零污染泄漏和清晰的严格联合契约：v1 原始响应、claims/evidence、内容哈希和审计链只读封存，不自动回放或复活；后续内容必须重新经过相关性、证据和 PublicationService 门禁。该决定仅覆盖情报阅读面，saved/daily、引用、版本/diff、关系纠正、来源和 AI 设置继续保留 v1，因而取代 ADR-0001 中“所有公开接口统一位于 `/api/v1`”的局部约束，不改变模块化单体决策。
