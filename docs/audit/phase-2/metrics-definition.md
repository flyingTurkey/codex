# 第12轮指标定义

指标版本：`phase2-audit-v1.0.0`。时区统一为UTC，展示可转换为Asia/Shanghai。Fixture、Mock、回填和TEST环境不得混入真实窗口。

## 北极星指标

```text
端到端有效情报可用率 =
同一版本化真人金标 Event 集合中，
同时在来源级目标时效内发现、正确事件化、非重复、
关键事实有当前有效证据、且可由目标内部用户检索和阅读的 Event 数
/
该金标集合中应发现的高价值 Event 数
```

版本字段必须包括金标版本、标注人/仲裁人、规则版本、代码提交、来源集合、窗口起止和排除项。当前真人金标为空，因此分子、分母和比例均为null。

## 诊断指标

| 指标 | 分子 | 分母 | 用途 |
|---|---|---|---|
| 发现覆盖率 | 时限内发现的金标Event | 应发现Event | 定位来源/调度损失 |
| 获取成功率 | 成功保存原始响应的获准请求 | 合规发起的请求 | 定位网络和来源损失 |
| 解析成功率 | 通过结构与非空正文门禁的版本 | 待解析有效版本 | 定位解析损失 |
| 正确事件化率 | 正确映射到目标Event的样本 | 已发现的金标样本 | 定位身份损失 |
| 非重复率 | 未错误重复展示的Event | 可用Event | 定位归并损失 |
| 关键事实证据覆盖 | 有当前有效定位证据的已发布关键事实 | 已发布关键事实 | 发布绝对门禁 |
| 可检索阅读率 | 目标用户通过搜索/Feed可读的合格Event | 合格Event | 定位投影/ACL损失 |
| R3绕过数 | 未审核R3进入受禁消费者的次数 | 不使用比例 | 必须为0 |
| R4泄露数 | R4进入普通响应的次数 | 不使用比例 | 必须为0 |

这些比例必须单列，禁止相乘后冒充北极星。

## 运行、成本与用户指标

- 来源延迟按来源级SLO计算P50/P95，重点来源15分钟只适用于明确获准高频接口。
- 队列报告深度和最老任务年龄；只报深度会掩盖饥饿。
- 成本使用整数最小货币单位和币种，分别报告模型、OCR、对象、带宽及单个有效Event成本。
- 被动浏览只使用不可回溯个人的聚合桶；收藏、反馈、订阅和主动下载另按功能数据政策统计。
- 没有真实模型、通知、国际来源、连续窗口或保留政策时值为null，并给出reason。
