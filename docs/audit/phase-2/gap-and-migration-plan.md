先解决普通用户的数据边界和Event身份，再扩来源。所有迁移先影子写、核对、再单次切换；不在一个轮次同时扩来源和改变公开身份。

## 关键迁移映射

- Publication：保留旧revision事实，新增event projection引用；双写核对后切读。
- Search：从item_id回填event_id，精确标识排序不变；risk字段拆分。
- Daily：历史snapshot保留旧标题/摘要，同时固化event_id映射，不重算历史。
- Saved/Collection：按不可变映射幂等回填；无法唯一映射的记录进入人工队列。
- Citation/URL：Event成为canonical；Item页面308，API返回Deprecation与Link。
- Claim/Evidence：不复制证据；Event投影引用已接受Item Claim集合并记录来源revision。
