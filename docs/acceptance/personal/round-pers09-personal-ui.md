# PERS-09 个人界面收敛验收

## 目标与边界

本轮把个人研究平台收敛到一个来源工作区和一致的内容语义。唯一来源入口为 `/sources`；旧审批、策略、连接器、试运行、审核和 R17 页面不再出现在导航，访问旧地址会重定向到新工作区。旧表与历史数据原样保留，结构删除留给 PERS-10。

## 验收映射

| 要求 | 实现与证据 |
| --- | --- |
| 单一来源中心 | URL 添加、启停、主题、画像覆盖、评分、多流、健康原因、自愈时间、活动与运行摘要集中在 `/sources` |
| 状态区分 | 分别投影用户启用、实际运行、熔断、配置失败、部分画像、预算暂停 |
| 内容语义 | Feed 卡片、搜索、详情和日报分别标示证据事实、AI 判断、未验证 AI、AI 处理失败 |
| 未验证内容可发现 | 与已发布内容共用时间线和搜索；日报使用 `UNVERIFIED_AI` 独立区块 |
| 健康通知 | 仅页面打开且获得浏览器授权后发送；只含来源名和安全原因；按 observation 去重，恢复可通知一次 |
| 保存反馈 | URL、启停、重探测、主题和画像覆盖均显示进行中、成功、失败原因及重试入口 |
| 可访问性 | 语义标题、键盘按钮/开关、Drawer 焦点管理、`role=status/alert` 状态播报及 token 对比色 |

## 安全断言

- `desired_enabled` 只表示 Owner 意图，页面不把它当作实际采集授权。
- 通知不包含正文、模型输出、Secret、Cookie、令牌或个人敏感信息。
- AI 处理失败只投影固定原因码；原始模型输出不进入 Feed、搜索、详情或日报。
- 本轮没有 Alembic 删除迁移，没有删除旧历史表。
