# PERS-08 自动关系、事件和型号归一验收

## 范围

本轮取消重复、事件、主题、关系和型号归一的新人工候选审核，改为保守、版本化、可撤销的自动关系。旧治理表和旧 API 保留兼容；自动化不得删除或覆盖原始内容与证据对象。

## 验收映射

- Alembic `0028_automatic_relationships` 保存决定版本、算法/模型版本、基点分数、理由代码、输入成员、Owner 纠正/撤销和失效后继链；迁移头唯一且上游为 `0027_ai_judgment_versions`。
- 高置信重复、同一事件、报告后续/调查、型号别名/版本继承、主题与相关内容由共享领域规则自动决定。硬冲突拒绝关系，重复处理同一输入保持幂等。
- 初报、续报和最终调查报告不会进入 `DUPLICATE`；厂商、媒体和独立验证角色不会折叠成不可区分的来源。
- Owner-only Event 详情 API 和页面支持撤销、拆分、保持独立及型号纠正。撤销按成员、关系种类和输入指纹抑制重建；内容哈希变化后产生新版本。
- `PublicationService` 在纠正事务中推进个人内容、信号、搜索和日报 generation，并写入缓存、搜索和日报 `UPSERT` 失效事件；事务失败不会暴露半更新投影。
- 旧候选表、读取 API 和历史页面仍存在；新增候选由数据库触发器拒绝，写 API 返回 409，工作台不再显示关系或型号决定入口。
- 关系成员对 Item、Document、DocumentVersion、Claim、Evidence 只使用 `RESTRICT` 外键，未提供任何自动删除路径。
