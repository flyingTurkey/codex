# 05｜AI 处理流水线与模型治理

## 1. AI 的角色

AI 是受控的信息处理器，不是事实来源、发布者、安全专家或法律解释者。

### 允许

- 内容分类和标签候选；
- 实体与关系候选；
- 原子事实与证据候选；
- 有证据约束的摘要和翻译；
- 近似重复、事件关联候选；
- 四川路桥相关性和应用场景初步分析；
- 日报语言组织。

### 禁止独立决定

- 法规是否现行有效；
- 文号、实施日期、标准号、伤亡和金额等关键字段；
- 事故原因、等级和责任；
- 产品宣传是否真实、是否符合认证或许可；
- 法律、安全、采购或工程操作结论；
- 最终发布状态。

## 2. 分步流水线

```text
规则预筛
→ 范围分类
→ 类型/标签分类
→ 事实与证据抽取
→ 实体归一候选
→ 近似重复/事件候选
→ 证据约束摘要
→ 发布前复核
→ 规则门禁
→ 人工审核或自动收录
```

分类、抽取、摘要和复核必须拆为独立步骤，不使用一个超长提示词一次完成。

## 3. 结构化输出

- 每次调用使用固定 JSON Schema；
- 额外字段、类型错误、非法枚举和缺少必填字段均拒绝；
- 关键事实必须包含 `evidence_id`；
- 无证据时返回 `null`、空数组或 `UNKNOWN`；
- 保存模型、参数、提示词、Schema、输入哈希、输出、耗时和成本；
- 原始模型输出只作为候选，经领域服务校验后才能写业务表。

`docs/codex-kit/assets/content.schema.json` 是发布后的只读模型，不得作为模型输出或发布命令输入。各步骤候选必须分别通过 `docs/codex-kit/assets/schemas/classify-output.schema.json`、`extract-output.schema.json`、`summarize-output.schema.json` 和 `verify-output.schema.json`；最终发布门禁只信任服务端从数据库和安全系统装配的权威上下文。

开发、演示或素材预览不要求人工预先计算证据摘要/输入哈希。生产流水线由服务端按固定规范化规则自动计算并校验 SHA-256；模型或客户端给出的哈希只可作为候选，不能决定完整性状态或阻塞早期开发。

## 4. Prompt Injection 防护

网页、PDF、OCR、隐藏文本、元数据和附件全部视为不可信数据：

- 文档放入明确的数据边界，不能充当系统指令；
- 模型无 Shell、数据库写入、对象存储遍历、内网或任意网络能力；
- AI Worker 只访问模型网关；
- 主动内容、脚本、宏、嵌入文件和隐藏文本先隔离；
- 检测“忽略指令、泄露提示词、执行命令、发送密钥”等模式并标记；
- 命中不自动丢弃整篇文档，但进入更高风险门禁；
- 模型输出中的 URL、HTML 和 Markdown 仍需重新验证和转义。

## 5. 模型网关

统一能力：

- 供应商和模型路由；
- 数据分级和允许模型策略；
- 请求限流、预算、超时和重试；
- 敏感信息扫描和脱敏；
- Prompt/Schema 注册；
- 调用追踪、成本和质量指标；
- Mock 模型用于 CI；
- 禁止业务代码直接调用供应商 SDK。

## 6. 事实抽取规则

- 一个 Claim 只表达一个事实；
- 同时保留原值和规范化值；
- 相对日期只有在基准日期明确时才换算；
- OCR、单位、名称或前后冲突时标记不确定；
- “据称、预计、力争、领先”等表述标记为 `reported_claim`；
- 安全原因和责任只抽取正式认定语境；
- 多来源冲突分别保留，不由模型裁决；
- 对数字、日期、编号使用规则校验器二次验证。

## 7. 摘要规则

摘要固定输出：

- `one_sentence`：80 个汉字以内；
- `why_it_matters`：120 个汉字以内；
- `key_points`：不超过 5 条；
- `applicable_scenarios`；
- `limitations`；
- `recommended_actions`：仅允许阅读原文、专业核验、加入关注、开展调研等低风险动作。

所有用户可见摘要字段必须只引用发布服务已接受的 Claim，并在结构化结果中列出 `used_claim_ids`；任何未接受、无证据或已失效的 Claim 都不得进入展示文本。R3 内容审核前不生成普通用户可见摘要，只返回题录白名单投影。

禁止：

- 把企业自述改写为平台认定；
- 生成原文没有的数字、日期、金额或伤亡；
- 独立判断事故责任或法律适用；
- 输出大段原文；
- 使用绝对化、营销化表述。

## 8. 评测与升级

离线评测包括：

- JSON Schema 通过率；
- 分类 Macro-F1；
- 事实准确率和召回率；
- 证据支持率；
- 数字/日期错误率；
- 无证据扩写率；
- 厂商声明归因准确率；
- 摘要忠实度；
- 单文档成本和 P95 时延。

升级顺序：

```text
固定金标集回放 → 历史生产样本回放 → 影子运行 → 小比例灰度 → 全量
```

任何关键指标回退或高风险错误增加都必须停止升级并回滚。

## 9. 降级策略

模型不可用时：

- 采集、原文存档、解析、精确去重和题录继续；
- AI步骤进入可重试队列；
- 已发布快照保持不变；
- 不以空摘要覆盖旧摘要；
- 后台显示 AI 积压和预计恢复影响。

具体提示词见 `assets/prompts/`。
