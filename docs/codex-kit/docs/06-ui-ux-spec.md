# 06｜UI/UX 设计规范（方案 1）

版本：`1.1.0-avocado`  
视觉真相：`assets/ui/references/selected-concept-01.png`  
详细实施规范：`docs/ui/`

## 1. 设计目标

平台应让用户在 10 秒内回答：发生了什么、与四川路桥有什么关系、来源和复核状态是什么、证据在哪里、下一步能做什么。

首期采用 AIHOT 式高密度时间线信息流，以低饱和牛油果色为主交互色。它不是新闻门户或 BI 大屏，而是证据化行业情报工作台。

## 2. 信息架构

一级导航：

1. 今日精选；
2. 全部动态；
3. 数字化；
4. 安全情报；
5. 行业日报；
6. 收藏；
7. 管理入口（按权限显示）。

`/`、`/selected`、`/all`、`/digital`、`/safety` 必须复用同一个 `IntelligenceFeedPage` 和 `IntelligenceCard`，不得各自开发平行信息流。

## 3. 首页与信息流

- 首页首屏直接展示更新时间、搜索、频道 Tab 和今日精选时间线；
- 今日新增、待审核、异常来源使用紧凑状态条或提示，不占用首屏大卡；
- 时间轴按 `activity_at` 展示，卡片同时明确原文发布时间和首次发现时间；
- API 返回扁平列表，前端按 `Asia/Shanghai` 日期分组；
- 使用 Cursor“加载更多”，不展示虚假总页数；
- 相关性、影响、权威、证据、置信和热度是独立维度，不能合并成模糊“可信度”。

## 4. 情报卡

左区顺序：

1. 来源、时间、内容类型；
2. 来源性质和人工复核状态；
3. 标题与一句话事实；
4. 与四川路桥的关系；
5. 场景、专业、地区和类型化标签。

右区顺序：

1. 可用的相关性/评分摘要；
2. 收藏；
3. 查看证据；
4. 证据类型、证据数量和状态；
5. 已更新、撤回、冲突等文档状态。

所有内容类型复用同一卡片，通过 `type_summary` 判别联合类型扩展。第 08 轮前没有真实评分时，隐藏评分区域，不生成演示分数。

## 5. 安全受限投影

R3 内容在人工审核前，普通用户只收到并显示标题、类型、官方来源、原文时间、首次发现时间、原文链接和待审核状态。摘要、伤亡、原因、责任、法规效力、评分和证据片段不得由 API 返回。

R4 不进入普通用户响应。不能先返回完整内容再由前端隐藏。

## 6. 详情与证据

详情依次展示：

1. 类型、来源性质、复核和发布状态；
2. 标题、一句话事实、来源与时间；
3. 为什么相关、限制和推荐动作；
4. 类型化字段；
5. 事实清单与证据；
6. 版本/事件时间线；
7. 相关内容、AI声明和纠错入口。

点击事实时高亮对应证据片段、页码/段落和文档版本。原文失效时保留存档版本和最后核验时间；撤回后旧摘要必须失效。

## 7. 审核工作台

- 左：风险、影响、置信和时效排序的队列；
- 中：原文/PDF及版本差异；
- 右：字段、证据、摘要和门禁；
- 底：固定决策栏；
- 高风险操作必须填写理由；
- 提交人与审核人职责分离；
- 客户端按钮只能请求 `PublicationService`，不能直接写发布状态。

## 8. 状态语义

- 主交互：牛油果绿；
- 数字化：低饱和蓝绿；
- 安全规定：琥珀；
- 安全案例：暗红；
- 已人工复核：绿色＋文字＋图标；
- 待复核：暖橙＋文字；
- 厂商声明：中性灰；
- 冲突/撤回：红色＋文字＋图标。

“官方一手来源”和“已人工复核”必须拆开，禁止使用“官方已核验”造成政府背书误解。

## 9. 响应式

- ≥1440px：216px 侧栏、80px 时间轴、248px 卡片证据区；
- 1024—1439px：紧凑侧栏，证据区可移到卡片底部；
- 768—1023px：抽屉导航，时间并入元数据，卡片单列；
- <768px：保证阅读、搜索、筛选、收藏和证据查看；管理后台不承诺完整体验。

## 10. 无障碍与状态

- WCAG 2.2 AA；
- 所有主任务可键盘完成；
- 焦点清晰，抽屉归还焦点；
- 关键状态不只用颜色；
- 尊重 `prefers-reduced-motion`；
- 必须实现 Loading、Empty、Error、Delayed、Restricted、Withdrawn、Conflict 和 No-AI 降级状态；
- 涉及前端的每轮运行 `make web-e2e` 与 `make web-a11y`。

## 11. 文案

- 明确使用“平台整理”“厂商声明”“官方一手来源”“已人工复核”“待核实”；
- 禁止“绝对安全、完全替代、行业第一、零风险”等无证据用语；
- 安全声明：平台内容仅供内部信息参考，不替代正式制度、专业审查和现场安全决策；
- AI声明：摘要由 AI 辅助生成，重要信息请以原文和人工审核结果为准。

设计 Token、组件清单、状态矩阵、演示样本和原型见 `assets/ui/` 与 `prototype/selected-feed/`。
