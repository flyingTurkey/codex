# 06｜UI/UX 设计规范

## 1. 设计目标

界面应让用户在 10 秒内回答：发生了什么、与四川路桥有什么关系、可信到什么程度、证据在哪里、下一步能做什么。

视觉关键词：专业、克制、可信、工程感、信息密度适中。避免新闻门户式大图堆叠和过度“AI霓虹”。

## 2. 响应式基准

- 1920×1080 和 2560×1440 为主要桌面目标；
- 内容最大宽度 1440px；
- 1440px 以下收起部分侧栏；
- 1024px 以下转换为单列或抽屉筛选；
- 首期不承诺小于 768px 的完整管理后台，但用户阅读页应可用。

## 3. 布局

- 顶部：产品名、全局搜索、数据更新时间、用户菜单；
- 左侧：一级导航和频道；
- 主区：页面标题、摘要指标、筛选/标签、内容列表；
- 右侧可选：今日提醒、来源健康或详情证据导航；
- 管理后台沿用同一设计系统，但以表格、分栏审核和状态信息为主。

## 4. 页面

### 首页

- 顶部不使用纯装饰 Hero，直接展示今日摘要；
- 四个指标：今日新增、精选、待审核、异常来源；
- 数字化精选、安全重点、近 7 日热点和日报；
- 清楚显示平台最后更新时间。

### 精选/全部动态

- 采用列表卡片而非瀑布流；
- 筛选条件固定在顶部或左侧；
- 精选与全部使用明确 Tab；
- 卡片支持紧凑/舒展两种密度；
- 分页使用“加载更多”或 Cursor，不显示不可达的总页数。

### 详情

自上而下：

1. 类型、状态、权威等级；
2. 标题、一句话事实、来源和时间；
3. 为什么相关、关键事实、限制；
4. 类型化字段；
5. 证据清单；
6. 事件时间线/相关内容；
7. AI声明、版本和纠错入口。

证据采用双栏或可展开抽屉，点击事实时高亮对应证据。

### 审核工作台

- 左：风险排序队列；
- 中：原文/PDF；
- 右：字段、证据、摘要和门禁；
- 审批区固定在底部；
- 高风险操作要求填写理由；
- 提交人与审核人职责分离。

## 5. 卡片最小字段

- 内容类型图标；
- 标题和一句话事实；
- 来源、发布时间、首次发现时间；
- 行业/场景/地区标签；
- 权威、证据和审核徽标；
- 为什么相关；
- 关键编号/日期/产品型号；
- 收藏与查看证据入口。

## 6. 状态视觉

- 数字化：蓝/青；
- 安全规定：琥珀；
- 安全事故：克制的暗红；
- 已核验：深蓝/绿色；
- 企业自述：灰紫；
- 未核实：灰色虚线；
- 撤回/冲突：红色文字与图标，不只依赖颜色。

颜色不能替代“事故等级、法规状态、审核状态”的文字。

## 7. 无障碍

- 正文对比度达到 WCAG AA；
- 所有操作可键盘完成；
- 焦点样式清晰；
- 图标按钮有可访问名称；
- 表格支持表头和范围；
- 图表提供文本替代；
- 不使用仅悬浮可见的关键事实；
- 动画尊重 `prefers-reduced-motion`。

## 8. 空态、加载与错误

- 首屏骨架只表达布局，不制造假内容；
- 无结果说明当前筛选并提供一键清除；
- 来源延迟明确显示“数据可能不完整”；
- 详情原文失效时保留版本并说明；
- AI处理中不显示虚构摘要；
- 管理后台错误必须给出可操作的重试、暂停或查看运行入口。

## 9. 文案规则

- 使用“平台整理”“厂商声明”“官方认定”“待核实”等清晰归因；
- 禁止“绝对安全、完全替代、行业第一、零风险”等无证据用语；
- 安全页面固定声明：平台内容仅供内部信息参考，不替代正式制度、专业审查和现场安全决策；
- AI内容固定声明：摘要由 AI 辅助生成，重要信息请以原文和人工审核结果为准。

设计令牌和页面清单见 `assets/ui/`。
