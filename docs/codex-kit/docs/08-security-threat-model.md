# 08｜安全威胁模型

## 1. 重点资产

- 企业身份、角色和部门信息；
- 来源账户、API密钥和抓取配置；
- 原始文档、附件和对象存储；
- 发布内容、证据、审核和审计；
- 模型请求、提示词、成本和评测数据；
- 数据库、队列、备份和监控系统。

## 2. 信任边界

互联网来源、上传文件、OCR文本、模型输出和用户输入全部不可信。采集区、AI区、应用区、数据区和管理区需网络与权限隔离。

## 3. P0 威胁与控制

| 威胁 | 强制控制 |
|---|---|
| SSRF/恶意重定向 | 域名白名单、DNS/IP复核、私网阻断、逐跳校验 |
| 恶意 HTML/PDF/压缩包 | 隔离下载、MIME嗅探、大小/页数/解压上限、杀毒、禁宏/脚本 |
| Prompt Injection | 数据/指令分离、模型无工具权限、风险检测、Schema和人工门禁 |
| XSS/内容劫持 | 纯文本优先、HTML白名单、CSP、输出编码 |
| 越权/IDOR | 服务端 RBAC+对象授权、职责分离、权限矩阵测试 |
| 密钥泄露 | Secret Manager、最小权限、日志脱敏、轮换 |
| AI错误高风险发布 | 证据绑定、规则校验、安全内容强制人审 |
| 伪造审核/评分或绕过发布门禁 | 单一 `PublicationService`、服务端权威上下文、发布表独立数据库写角色、默认拒绝 |
| 版权/全文滥用 | 来源策略、摘录上限、授权台账、下架流程 |
| 隐私/名誉风险 | 最小化、脱敏、只引用正式认定、未结案明确标记 |
| CSV公式注入 | 对 `= + - @` 开头单元格转义 |
| 审计篡改 | 只追加、每日哈希清单、独立备份 |

## 4. 权限

- `viewer`：浏览、搜索、收藏；
- `editor`：编辑并提交；
- `reviewer`：审核发布；
- `source_admin`：来源和采集；
- `platform_admin`：平台和用户；
- `auditor`：只读审计。

安全规定和事故内容的提交人不得审核自己提交的内容。

模型、采集器、普通 API 和管理员连接均不得直接写发布表；它们只能提交候选或审核动作，由 `PublicationService` 基于数据库现状重新执行门禁。R3 审核前仅开放题录白名单投影，R4 不进入普通用户查询、搜索、日报或导出。

## 5. 数据分级

- `PUBLIC_SOURCE`：公开来源数据；
- `SRBG_INTERNAL`：企业内部整理和反馈；
- `DEPARTMENT_ONLY`：部门专题和批注；
- `RESTRICTED`：敏感来源配置、密钥和受限文档。

首期外部模型只处理批准的公开来源最小文本；内部批注和受限内容不发送到外部模型。

## 6. 文件处理

- 对象存储私有；
- 下载使用短期签名 URL；
- 浏览器不直接渲染原始 HTML；
- PDF 采用隔离预览；
- Office 文档转安全格式后查看；
- 记录 SHA-256、MIME、大小、扫描结果和解析器版本。

## 7. 审计事件

必须记录：登录失败、权限变更、来源启停、连接器变更、提示词/模型变更、内容提交、批准、拒绝、纠错、撤回、批量导出、受限文档访问和管理员重跑。

审计日志包含操作者/代理、请求 ID、对象、前后摘要、时间、来源 IP、审批链和发布修订。

## 8. 上线安全门禁

- 威胁模型评审完成；
- 依赖、镜像、密钥和 IaC 扫描通过；
- SSRF、XSS、IDOR、越权、恶意文件和 Prompt Injection 测试通过；
- 无高危漏洞；
- WAF、CSP、备份、告警和应急联系人已配置；
- 恢复和撤回演练通过。
