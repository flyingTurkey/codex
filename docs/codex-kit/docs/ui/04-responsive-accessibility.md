# UI 04｜响应式与无障碍

## 1. 响应式规则

| 视口 | 侧栏 | 时间轴 | 卡片证据区 | 筛选 |
|---|---|---|---|---|
| ≥1440px | 216px 完整 | 80px 竖轴 | 248px 右栏 | 弹层/侧栏 |
| 1280—1439px | 200—216px | 72—80px | 220px 右栏 | 弹层 |
| 1024—1279px | 72px 图标栏 | 保留或缩窄 | 移到卡片底部 | 抽屉 |
| 768—1023px | 抽屉导航 | 时间并入元数据 | 卡片底部 | 抽屉 |
| <768px | 顶部紧凑导航 | 无竖轴 | 纵向区块 | 全宽抽屉 |

管理后台首期不承诺小于 768px 的完整操作，但不能出现不可关闭弹层或横向溢出导致关键操作不可达。

## 2. 文本与密度

- 桌面摘要建议最多 2—3 行，但完整事实可通过详情访问；
- 不对文号、标准号、DOI 和关键日期进行中间省略；
- 紧凑模式可以减少标签和空白，不能隐藏来源、状态和证据入口；
- 用户放大到 200% 时，阅读页仍能完成搜索、筛选、打开详情和查看证据。

## 3. 键盘与焦点

- 跳过链接直达主内容；
- 导航、Tab、筛选、收藏、证据、加载更多均可键盘操作；
- 使用语义 `button`、`a`、`nav`、`main`、`article`；
- 焦点环使用 `color.focus`，不只改变背景色；
- 抽屉打开时使用焦点陷阱，Esc 关闭，关闭后归还焦点；
- 收藏按钮通过 `aria-pressed` 表达状态；
- Tab 使用 `role=tablist/tab` 和 `aria-selected`。

## 4. 颜色与图标

- 正文和交互文本达到 WCAG 2.2 AA；
- 风险、撤回、冲突、待复核均配文字；
- 图标按钮提供可访问名称；
- Iconoir 图标统一 1.5px 描边，活动态可提高到 2px；
- 正式 Logo 缺失时使用文本，不手绘或生成仿冒 Logo。

## 5. 动效

- Hover/Focus 140—180ms；
- 抽屉 220ms；
- 不使用滚动视差、闪烁和自动轮播；
- 尊重 `prefers-reduced-motion`，关闭非必要动效。

## 6. 测试基线

- axe：无 critical/serious；
- 键盘：无焦点丢失、无键盘陷阱；
- 对比度：常规文字 ≥4.5:1，大字 ≥3:1；
- 页面缩放：200%；
- 高对比/强制色模式下关键状态可读；
- Playwright 覆盖搜索、Tab、筛选、收藏、证据抽屉和空态恢复。
