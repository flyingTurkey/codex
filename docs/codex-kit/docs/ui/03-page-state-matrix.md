# UI 03｜页面与状态矩阵

机器可读清单：`assets/ui/page_state_matrix.csv`

## 1. 用户端共用壳层

`/`、`/selected`、`/all`、`/digital`、`/safety` 共用 `IntelligenceFeedPage`，只改变模式、频道、默认筛选和页头文案，不创建平行卡片。

| 路由 | 默认内容 | 关键状态 |
|---|---|---|
| `/` | 紧凑今日要点＋今日精选时间线 | 新鲜、来源延迟、部分数据、无精选 |
| `/selected` | 通过精选门禁的发布修订 | 空态、Cursor、已更新、撤回 |
| `/all` | 自动收录池的可见投影 | 机器整理、待复核、R3受限、R4不可见 |
| `/digital` | 案例、论文、软件、物联网、低空、AI设备 | 厂商声明、研究证据、成熟度未知 |
| `/safety` | 规定与安全案例 | 法规状态未知、初报/调查/整改、人工复核 |
| `/items/:id` | 单条情报与证据 | 证据联动、冲突、版本、原文失效 |
| `/events/:id` | 事件生命周期 | 初报、续报、调查、处罚、整改关系 |
| `/search` | 精确编号＋模糊搜索 | 无结果、纠错提示、ACL过滤 |
| `/daily` | 固定日报快照 | 草稿、已发布、来源异常说明 |
| `/saved` | 收藏与集合 | 首次空态、集合为空、项目已撤回 |

## 2. 情报卡投影

### 完整发布投影

显示来源、时间、类型、标题、一句话事实、相关性理由、标签、分项摘要、证据状态、复核状态、收藏和证据入口。

### R3 受限投影

只显示服务端白名单字段。卡片用“待审核”说明为什么摘要和敏感字段暂不可见，不出现空白假骨架。

### 撤回投影

保留标题、来源、时间和撤回原因/时间，隐藏已失效结论，提供历史修订与原文版本入口。

### 原文失效投影

保留存档版本并显示最后核验时间，原文按钮改为不可用或“查看存档”，不得静默跳转失败。

## 3. 安全频道固定声明

> 平台内容仅供内部信息参考，不替代正式制度、专业审查和现场安全决策。法规效力、事故原因、责任和伤亡等信息以有权机关原文及人工审核结果为准。

## 4. AI 固定声明

> 摘要由 AI 辅助生成，重要信息请以原文和人工审核结果为准。

## 5. 页面完成定义

页面只有同时满足以下条件才完成：

- 接入真实 API 或可追溯固定样本，不使用页面内硬编码假接口；
- Loading、Empty、Error、Delayed、Restricted、Withdrawn 状态至少覆盖适用项；
- 键盘可完成主任务；
- 文字与图标共同表达关键状态；
- 1920×1080、1440×900、1024×768 完成视觉与交互回归；
- 涉及阅读页时验证 768px 宽度；
- 通过 `make web-e2e` 与 `make web-a11y`。
