# UI 01｜设计系统实施规范

单一令牌源：`assets/ui/design_tokens.json`  
CSS 预览变量：`assets/ui/theme.css`

## 1. 技术落点

- 正式项目：Nuxt 4、Vue 3、TypeScript strict、Tailwind CSS、Nuxt UI 4；
- UI 原语：`packages/ui`；
- 业务页面与数据适配：`apps/web`；
- 图标：Iconoir，默认 20px、1.5px 描边；
- 不引入第二套全量组件库；
- 原型目录仅为视觉与交互参考，不作为生产依赖。

## 2. 颜色规则

| 用途 | Token | 规则 |
|---|---|---|
| 页面背景 | `color.canvas` | 所有阅读页底色 |
| 卡片/抽屉 | `color.surface` | 主表面 |
| 主操作 | `brand.600/700` | 按钮、当前导航、焦点 |
| 数字化 | `digital.*` | 类型标签和时间轴节点 |
| 安全规定 | `safetyRegulation.*` | 法规/标准类型 |
| 安全案例 | `safetyCase.*` | 事故/处罚/撤回 |
| 已人工复核 | `verified.*` | 必须同时有文字和图标 |
| 待复核 | `reviewPending.*` | 不等于错误 |
| 厂商声明 | `vendorClaim.*` | 不使用绿色 |
| 冲突/撤回 | `conflict.*` | 不只依赖颜色 |

正文文字优先使用 `ink.700/900`，元数据使用 `ink.500/600`。`brand.500` 不用于小字号正文。

## 3. 字体层级

| 元素 | 规格 |
|---|---|
| 页面标题 | 24/32px，700 |
| 卡片标题 | 16/24px，600—700 |
| 正文摘要 | 14/22px，400 |
| 相关性理由 | 14/22px，400；前缀 600 |
| 元数据 | 12/18px，400—500 |
| 标签/徽标 | 12/18px，500—600 |
| 分项数字 | 24/28px，700，使用等宽数字特性 |

中文优先使用 Noto Sans SC / Source Han Sans SC，系统缺失时回退到苹方、微软雅黑和 system-ui。

## 4. 桌面布局

│ 品牌与主导航       │ 页面标题、更新时间                     搜索、筛选 │
│                   │ 频道 Tab                                               │
│                   │ 80px 时间轨 │ 情报卡正文        │ 248px 证据摘要 │
│ 管理入口与用户     │ 80px 时间轨 │ 情报卡正文        │ 248px 证据摘要 │

- Feed 最大宽度：1720px；
- 左侧栏：216px；
- 卡片最小高度：188px；
- 卡片间距：10px；
- 卡片圆角：12px；

- 证据摘要区：248px。

## 5. 组件外观

### 导航项

- 高度 52—56px；
- 激活态使用 `brand.100` 背景和 `brand.700` 前景；
- 图标与文字间距 12—16px；
- 管理入口与用户信息固定在侧栏底部。

### Tab

- 高度 48—52px；
- 激活态为 2px 牛油果绿下划线；
- Tab 可横向滚动但不可截断文字；
- 键盘焦点独立于激活态。

### 情报卡

- 白色表面、1px 边框、极弱阴影；
- Hover 只加深边框和极弱阴影；
- 左区依次为来源行、标题、摘要、相关性、标签；
- 右区依次为相关性摘要、收藏、证据入口、证据状态；
- 卡片本体不承担发布决策，所有状态来自服务端投影。

### 抽屉

- 证据抽屉桌面宽度 420—480px；
- 打开后焦点进入抽屉，关闭后回到触发按钮；
- Esc 和显式关闭按钮均可关闭；
- 不能只在抽屉内展示安全关键限制，卡片本身也要显示状态。

## 6. 状态层次

每条内容至少区分三类状态，不能混成一个徽标：

1. 来源性质：官方一手、同行企业、论文、厂商、媒体；
2. 处理/复核状态：机器整理、待复核、已人工复核；
3. 发布/文档状态：已发布、已更新、已撤回、原文失效、存在冲突。

## 7. Tailwind 与 Nuxt UI 映射

- 由构建脚本或 TypeScript 常量读取 JSON Token；
- 不在页面组件中散落十六进制色值；
- Nuxt UI 仅承担基础按钮、输入、弹层、表单和表格；
- `IntelligenceCard`、`EvidenceDrawer`、`TimelineFeed` 等业务组件必须在本项目实现；
- 所有组件提供 Loading、Empty、Error、Disabled、Focus 状态的 Story/测试。
