# UI 00｜方案 1 视觉方向

版本：`1.1.0-avocado`  
选择日期：`2026-07-13`  
视觉真相：`assets/ui/references/selected-concept-01.png`

## 1. 设计结论

首期采用“AIHOT 式高密度时间线信息流”，主题为低饱和牛油果色。首页不是 BI 大屏，也不是图片新闻门户，而是一张持续更新、可筛选、可核验证据的行业情报时间线。

用户应在 10 秒内看清：

1. 发生了什么；
2. 属于数字化还是安全；
3. 与四川路桥有什么关系；
4. 来源性质和复核状态是什么；
5. 证据在哪里；
6. 是否值得收藏、转发或进一步研究。

## 2. 第一性原理

平台的价值不是“文章很多”，而是降低以下认知成本：

- 发现成本：从多源内容中快速发现真正相关的信息；
- 判断成本：区分官方事实、论文证据、厂商声明和平台归纳；
- 核验成本：从摘要一键返回原文、页码和证据片段；
- 行动成本：知道这条信息为何与四川路桥相关、下一步应做什么。

所以首屏优先级固定为：事实与归因 > 相关性 > 证据与状态 > 操作 > 装饰。

## 3. 从 AIHOT 借鉴什么

- 固定左侧导航；
- 简洁页头、搜索与频道 Tab；
- 按日期和时间组织的高密度列表；
- 克制边框、圆角和极弱阴影；
- 卡片内部以文字为主，不依赖缩略图；
- 精选、全量、日报、专题、收藏等内容产品心智。

## 4. 必须改造什么

AIHOT 的“资讯卡”改造为“情报卡”，每条至少增加：

- `与四川路桥的关系`；
- 来源角色：官方一手、论文、企业发布、媒体转述等；
- 人工复核状态：机器整理、待复核、已人工复核；
- 证据类型和入口；
- 安全内容的服务端受限投影；
- 可解释的相关性/影响/权威/证据等分项，不使用模糊的单一“可信度”。

## 5. 视觉语汇

关键词：专业、安静、可信、工程感、高信息密度。

- 页面底色：浅暖灰绿；
- 主表面：白色；
- 主交互色：低饱和牛油果绿；
- 正文：深橄榄黑；
- 数字化：低饱和蓝绿；
- 安全规定：琥珀；
- 安全案例：克制暗红；
- 厂商声明：中性灰；
- 待复核：暖橙；
- 圆角：4—12px；
- 阴影：仅用于悬浮和抽屉，不制造漂浮卡片墙。

## 6. 禁止项

- 不复制 AIHOT 的 Logo、名称和品牌图形；
- 不使用霓虹、渐变、玻璃拟态、纯黑大面板；
- 不使用大幅 Hero、装饰插画或新闻缩略图占据首屏；
- 不用品牌绿同时表达“可点击”和“已核验”；
- 不把“来源是官方”写成“官方已核验”；
- 不以单一数字替代证据状态和分项评分；
- 不在浏览器取得完整 R3/R4 内容后再前端隐藏。
