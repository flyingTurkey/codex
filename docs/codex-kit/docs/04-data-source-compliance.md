# 04｜数据源、采集与合规规范

## 1. 来源策略

首期追求高价值来源稳定覆盖，不追求抓取总量。任何来源必须同时满足“业务价值、身份可信、访问合规、可稳定解析、可合理展示”后才能启用。

## 2. 权威等级

| 等级 | 定义 | 可否单独支撑核心事实 |
|---|---|---|
| A0 | 国家法律法规/标准平台、正式事故调查报告 | 可以，但需核对版本和状态 |
| A1 | 国务院、部委、省级政府及主管部门正式发布 | 可以 |
| B1 | 正式期刊、科研院所、行业学会/协会 | 可支撑研究结论，不能单独认定法规效力或事故责任 |
| B2 | 央国企、软件商、设备商官方发布 | 只能证明企业发布或自述 |
| C1 | 权威行业/科技媒体 | 作为线索或辅助证据 |
| C2 | 一般媒体、自媒体、社交内容 | 只进入待核实线索池 |

来源权威性必须结合事实类型判断。企业官网对产品发布是一手来源，对产品真实效果不是独立证据。

## 3. 来源生命周期

```text
CANDIDATE → COMPLIANCE_REVIEW → FIXTURE_TEST → APPROVED → ACTIVE
ACTIVE → DEGRADED / PAUSED / RETIRED
```

所有 `assets/source_registry.csv` 种子初始为 `CANDIDATE` 且 `enabled=false`。

## 4. 启用门禁

每个来源必须：

1. 确认真实域名、主管单位、栏目所有者和联系方式；
2. 检查 robots、服务条款、API条款和访问频率；
3. 明确可保存和可展示范围：全文、题录、短摘要、缩略图或仅链接；
4. 抽取至少 30 条样本，覆盖分页、详情、附件和异常页面；
5. 保存脱敏固定样本并通过连接器契约测试；
6. 记录页面结构指纹、基准内容数量和最近发布日期；
7. 配置超时、速率、退避、重试、熔断和 User-Agent；
8. 配置负责人、复审日期和异常处理方式；
9. 通过 SSRF、重定向、MIME、文件大小和恶意文件测试；
10. 经来源管理员批准后才能切换为 `ACTIVE`。

## 5. 采集优先级

依次采用：

1. 正式 API；
2. RSS/Atom；
3. Sitemap 和公开结构化列表；
4. 静态 HTML；
5. 公开 PDF/附件；
6. 经批准的少量 Playwright 动态采集。

禁止绕过登录、验证码、付费墙、Cookie 同意机制、IP限制或其他访问控制。

## 6. 内容与版权展示

默认策略：

- 政府文件：保存合法取得的原始证据，前台展示结构化事实、自写摘要和官方链接；
- 学术论文：展示题录、摘要、DOI、关键词和原文入口，全文按开放许可或机构授权处理；
- 企业和媒体：展示必要短摘要、事实字段和原文链接，不搬运全文和图片；
- 标准：展示名称、编号、状态和实施日期，全文只通过官方开放入口；
- 事故图片：默认不采集、不展示血腥画面，涉及个人和项目敏感信息需脱敏。

每个来源必须配置：

- `storage_policy`；
- `display_policy`；
- `fulltext_allowed`；
- `image_allowed`；
- `excerpt_max_chars`；
- `attribution_template`；
- `license_reviewed_at`。

## 7. 采集运行规则

- 只允许请求来源和附件白名单域名；
- 每次重定向重新校验域名、DNS 和 IP；
- 拒绝回环、私网、链路本地、云元数据和非 HTTP(S) 协议；
- 默认连接/读取超时 10/30 秒，单来源可向下调整；
- 默认最多 3 次重试，指数退避并加入抖动；
- 单文件大小、页数、解压大小和附件数量均设上限；
- 识别 MIME 而不是信任扩展名；
- 条件请求优先使用 ETag 和 Last-Modified；
- 原始响应写入对象存储后再解析；
- 连续失败达到阈值后自动熔断并告警。

## 8. 静默漏采检测

HTTP 200 不等于采集成功。健康监测同时检查：

- 列表条目数量；
- 最新内容发布日期；
- 关键选择器和结构指纹；
- 正文长度、空正文率和附件率；
- 与历史基线的字段分布差异；
- 探针内容是否仍可发现；
- 同类来源是否出现平台遗漏的已知重要内容。

## 9. 首批启用顺序

首轮优先从以下类别选 6 个来源做纵向切片：

- 交通运输部政府信息公开；
- 应急管理部事故调查报告；
- 四川省交通运输厅；
- 中国公路学报；
- OpenAlex API；
- 大疆行业应用或一个企业案例源。

完成 6 个来源并连续稳定运行后，扩展至 20 个；达到 14 天质量门槛后再扩展至 30—50 个。

## 10. 公开化前置审查

首期仅限企业内部。若未来面向社会开放，必须在公开前完成新闻信息服务、算法推荐、生成内容标识、版权、个人信息、数据跨境、投诉下架和备案义务专项法律评估，不能直接把内部版切换为公网版。
