# 第 05 轮：数字化转型案例

```text
执行第05轮：完成数字化典型案例的采集、结构化、审核和展示。

读取：docs/codex-kit/docs/01-PRD.md、docs/codex-kit/docs/02-content-model.md、docs/codex-kit/assets/taxonomy.yaml、docs/codex-kit/assets/sample_items.json、docs/codex-kit/assets/ui/copy_examples.md。

来源：选择一个政府/行业协会案例源和一个企业案例源，各自保存固定样本。

必须交付：
- digital_case_profile及企业、技术、项目实体关系；
- 工程专业、生命周期、技术标签、场景、成熟度、部署规模；
- claimed_outcomes与verified_outcomes严格分开；
- 适用性、复制条件、限制和风险字段；
- 政府案例与企业自述使用不同证据徽标和门禁；
- 数字化频道、筛选、卡片和详情；
- 审核页支持修改分类、场景、成熟度和归因；
- 相关性评分v1，公路/桥梁/隧道和四川加权；
- 固定样本、契约、规则、E2E和无障碍测试。

硬性规则：
- “领先、提升、节约”等量化结果保持发布方归因；
- 无独立证据不得进入verified_outcomes；
- 无项目数量、运行时间或验收证据时成熟度不能自动判为规模应用；
- 推荐动作只允许阅读、收藏、关注和技术调研，不给采购结论。

验收：政府典型案例可在严格门禁后进入精选；企业案例自动收录但带厂商声明，未经审核不进入精选；所有量化成效可点回证据。

不做：论文、产品型号库、语义聚类、真实LLM。
```
