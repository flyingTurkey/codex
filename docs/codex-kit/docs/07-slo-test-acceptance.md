| 门户/API 月度可用性 | 内测 ≥99.5%，正式推广 ≥99.9% |
| API 普通读取 P95 | ≤500ms |
| 搜索 P95 | ≤800ms |
| 一级来源采集成功率 | ≥99% |
| 一级安全/法规来源发现延迟 | P95≤30分钟 |
| 一般数字化来源发现延迟 | P95≤4小时 |

| 来源结构异常发现 | ≤15分钟 |
| RPO | ≤15分钟 |
| RTO | ≤4小时 |

## 3. 金标集

首期至少建立：

- 500 份代表性文档；
- 300 对重复/非重复样本；
- 100 个事件聚类；
- 200 条关键事实和证据标注；
- 100 条真实搜索问题；
- HTML、普通 PDF、扫描 PDF、表格和附件套件均有覆盖。

金标集版本化，测试数据不包含未授权全文和非必要个人信息。

## 4. 测试分层

### 单元

日期、文号、伤亡、金额、状态机、权限矩阵、评分、门禁、关系和幂等键。

### 采集器契约

固定响应验证发现、分页、游标、标题、日期、附件、条件请求、结构异常和空正文失败。

### 解析黄金

验证正文、页码、坐标、表格、元数据、证据定位和解析器升级差异。

### 集成

使用临时 PostgreSQL、Redis、MinIO 验证任务重试、重复投递、Outbox、对象写入、迁移、索引和发布快照。

### 端到端

每个内容类型至少一条：

```text
固定来源样本 → 采集 → 解析 → 事实/证据 → 审核 → 发布 → 搜索/详情
```

### AI评测

CI 使用固定输入和 Mock 输出；真实模型在独立评测流水线运行。

### 安全

覆盖 SSRF、XSS、恶意重定向、错误 MIME、压缩炸弹、Prompt Injection、IDOR、越权审核、日志泄露和 CSV 公式注入。

## 5. 发布门禁

合并到主分支前：

```bash
make lint
make typecheck
make test
make contract-test
make security-check
```

涉及内容流水线：

```bash
make fixture-replay
make quality-gate
```

涉及前端：

```bash
make web-e2e
make web-a11y
```

## 6. 内测验收

- 20 个批准来源稳定运行 14 天；
- 数字化和安全各至少 8 个有效来源；
- 采集—处理—审核—发布—检索闭环全通；
- 20 名种子用户连续使用两周；
- 首页 Top 20 内容人工“有用”率 ≥70%；
- 70% 种子用户完成检索、证据查看、收藏或导出；
- 已知重要样本发现召回率 ≥90%；
- 审核员确认工作台降低重复阅读成本；
- 无 P0/P1 未解决安全问题。

## 7. 灾备验收

- 数据库时间点恢复；
- 对象存储恢复；
- Redis 清空后重建未完成任务；
- Worker 中断后幂等重放；
- 发布快照和审计校验；
- 每季度恢复演练一次并记录实际 RPO/RTO。
