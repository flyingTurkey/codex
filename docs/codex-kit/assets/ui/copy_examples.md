# UI 示例文案

所有示例仅用于开发占位，必须保留“演示数据”标识。

## 数字化案例

**【演示】某高速公路隧道群试点 AI 视频巡检**

发布方称，该项目在既有视频系统上增加边缘 AI 识别，用于发现未佩戴防护用品和危险区域闯入。

- 标签：隧道｜AI视觉｜边缘计算｜安全监测
- 成熟度：单项目应用
- 证据：企业官方发布
- 仍需核验：误报率、漏报率、正式验收结果
- 与四川路桥相关：可作为隧道智慧工地方案调研线索

## 期刊论文

**【演示】基于数字孪生的桥梁施工风险动态评估研究**

论文提出将 BIM 模型、现场传感数据和施工进度关联，用于动态识别桥梁施工风险。

- 标签：桥梁｜数字孪生｜风险评估｜论文
- 证据：同行评议
- 限制：研究结论不等于已经规模化应用

## 低空装备

**【演示】面向桥梁缆索巡检的无人机载荷方案发布**

该方案面向桥梁高空构件图像采集，并提供航线规划和缺陷标注功能。

- 证据：厂商声明
- 合规提醒：产品发布不代表已经满足项目所在地空域、适航和作业许可要求

## 安全规定

**【演示】某主管部门发布施工现场重大事故隐患判定文件**

- 状态：待人工核对是否现行有效
- 强制字段：发布机关、文号、发布日期、实施日期、替代文件
- 操作：查看原文｜查看版本关系｜请安全部门核验

## 安全案例

**【演示】某桥梁施工事故调查报告公布**

平台仅按正式报告展示事故经过、调查认定原因和整改建议。

- 证据：官方一手来源
- 发布状态：强制人工复核
- 提示：不得根据初报或媒体报道自行推断事故责任
