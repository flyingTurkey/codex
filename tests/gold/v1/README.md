# 第 11 轮版本化金标集

当前版本 `1.0.0-seed` 只交付目录、清单和评测框架，真实样本数均为 0，因此 required check 必须失败。不得复制生产正文、生成伪样本或降低 `quality_gates.json` 阈值。

清单的五个数组分别承载 500 文档、300 重复对、100 事件簇、200 事实证据标注和 100 搜索问题。每条记录后续必须包含批准的素材授权、稳定 ID、标注者/复核者、创建时间、版本与内容哈希；数据引入由质量所有者 CODEOWNERS 审批。

运行 `make golden-replay` 统计真实条目并执行门禁；未达到任一最低数量时返回非零退出码。所有质量报告必须引用本清单版本、文件 SHA-256 与策略 SHA-256。
